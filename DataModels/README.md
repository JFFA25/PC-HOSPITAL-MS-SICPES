# DataModels

![DataModels](https://img.shields.io/badge/DataModels-6A5ACD?style=for-the-badge&logo=databricks&logoColor=white)

Este directorio agrupa los modelos de aprendizaje automático utilizados en el proyecto, organizados en dos grandes bloques según su paradigma de entrenamiento:

- `Supervised_Lms/` - Modelos de aprendizaje supervisado.
- `Unsupervised_Lms/` - Modelos de aprendizaje no supervisado.
