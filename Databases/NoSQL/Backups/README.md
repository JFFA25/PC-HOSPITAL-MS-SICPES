# Backups

![Backups](https://img.shields.io/badge/Backups-8A2BE2?style=for-the-badge&logo=cloud&logoColor=white)

Esta carpeta se encuentra en `Databases/NoSQL/Backups`.

Contiene las copias de seguridad y archivos de respaldo para bases de datos NoSQL. Aquí se guardan exportaciones de colecciones, scripts de backup y notas para restauración.

> Mantén aquí los respaldos de la base de datos NoSQL organizados y accesibles.
