# Backups

![Backups](https://img.shields.io/badge/Backups-8A2BE2?style=for-the-badge&logo=cloud&logoColor=white)

Esta carpeta se encuentra en `Databases/SQL/Backups`.

Contiene las copias de seguridad y los archivos de respaldo para bases de datos relacionales. Aquí se deben guardar dumps, scripts de exportación/importación y notas necesarias para restaurar datos.

> Usa este espacio para mantener respaldos SQL organizados y fáciles de recuperar.
