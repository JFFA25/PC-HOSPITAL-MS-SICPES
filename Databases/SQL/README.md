# SQL

![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=for-the-badge&logo=mysql&logoColor=white) ![SQL](https://img.shields.io/badge/SQL-339999?style=for-the-badge&logo=database&logoColor=white)

Esta carpeta se encuentra en `Databases/SQL` y agrupa la documentación y los recursos relacionados con bases de datos relacionales.

## Subcarpetas

- `Backups/` - Copias de seguridad y respaldos de bases de datos.
  ![Backups](https://img.shields.io/badge/Backups-8A2BE2?style=for-the-badge&logo=cloud&logoColor=white)
- `DD/` - Diccionario de datos, definiciones de tablas y columnas.
  ![Data Dictionary](https://img.shields.io/badge/Data%20Dictionary-FF8C00?style=for-the-badge&logo=book&logoColor=white)
- `ERD/` - Diagramas de Entidad-Relación.
  ![ERD](https://img.shields.io/badge/ERD-0052CC?style=for-the-badge&logo=drawio&logoColor=white)
- `RM/` - Modelos relacionales, esquemas y normalización.
  ![Relational Model](https://img.shields.io/badge/Relational%20Model-32CD32?style=for-the-badge&logo=database&logoColor=white)
