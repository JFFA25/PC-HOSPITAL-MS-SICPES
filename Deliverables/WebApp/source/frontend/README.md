# Frontend

Esta carpeta se encuentra en `Deliverables/WebApp/source/frontend` y contiene el código fuente del frontend de la aplicación web del sistema SICPES.

## Contenido

En esta carpeta encontrarás:

- Componentes y páginas de la interfaz de usuario.
- Estilos y temas de la aplicación.
- Configuración del cliente HTTP.
- Recursos estáticos y assets.

> Este código constituye la parte cliente de la aplicación web.
