# WebApp

![WebApp](https://img.shields.io/badge/WebApp-4CAF50?style=for-the-badge&logo=react&logoColor=white) ![Deliverables](https://img.shields.io/badge/Deliverables-339999?style=for-the-badge&logo=rocket&logoColor=white)

Esta carpeta se encuentra en `Deliverables/WebApp` y agrupa la documentación, el código fuente y los artefactos de distribución de la aplicación web del sistema SICPES.

## Subcarpetas

- `DeployManual/` - Manual de despliegue e instrucciones de instalación de la aplicación web.
  ![Deploy](https://img.shields.io/badge/Deploy%20Manual-8A2BE2?style=for-the-badge&logo=readthedocs&logoColor=white)
- `UserManual/` - Manual de usuario con guías de uso e instrucciones para el usuario final.
  ![User Manual](https://img.shields.io/badge/User%20Manual-FF8C00?style=for-the-badge&logo=book&logoColor=white)
- `source/` - Código fuente de la aplicación web, dividido en backend y frontend.
  ![Source](https://img.shields.io/badge/Source-32CD32?style=for-the-badge&logo=code&logoColor=white)
