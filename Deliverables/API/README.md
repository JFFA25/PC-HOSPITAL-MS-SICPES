# API

![API](https://img.shields.io/badge/API-FF6B6B?style=for-the-badge&logo=swagger&logoColor=white) ![Deliverables](https://img.shields.io/badge/Deliverables-339999?style=for-the-badge&logo=rocket&logoColor=white)

Esta carpeta se encuentra en `Deliverables/API` y agrupa la documentación, el código fuente y los artefactos de distribución de la API REST del sistema de gestión hospitalaria SICPES.

## Subcarpetas

- `DeployManual/` - Manual de despliegue e instrucciones de instalación de la API.
  ![Deploy](https://img.shields.io/badge/Deploy%20Manual-8A2BE2?style=for-the-badge&logo=readthedocs&logoColor=white)
- `build/` - Artefactos compilados y listos para producción.
  ![Build](https://img.shields.io/badge/Build-0052CC?style=for-the-badge&logo=githubactions&logoColor=white)
- `source/` - Código fuente de la API REST.
  ![Source](https://img.shields.io/badge/Source-32CD32?style=for-the-badge&logo=nodedotjs&logoColor=white)

> Usa este README como guía rápida para identificar el propósito de cada carpeta dentro de la estructura API.
