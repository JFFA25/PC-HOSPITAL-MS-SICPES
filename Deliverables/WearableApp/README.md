# WearableApp

![WearableApp](https://img.shields.io/badge/WearableApp-4CAF50?style=for-the-badge&logo=googlefit&logoColor=white) ![Deliverables](https://img.shields.io/badge/Deliverables-339999?style=for-the-badge&logo=rocket&logoColor=white)

Esta carpeta se encuentra en `Deliverables/WearableApp` y agrupa la documentación, el código fuente y los artefactos de distribución de la aplicación wearable del sistema SICPES.

## Subcarpetas

- `DeployManual/` - Manual de despliegue e instrucciones de instalación de la aplicación.
  ![Deploy](https://img.shields.io/badge/Deploy%20Manual-8A2BE2?style=for-the-badge&logo=readthedocs&logoColor=white)
- `UserManual/` - Manual de usuario con guías de uso e instrucciones para el usuario final.
  ![User Manual](https://img.shields.io/badge/User%20Manual-FF8C00?style=for-the-badge&logo=book&logoColor=white)
- `build/` - Artefactos compilados y listos para producción.
  ![Build](https://img.shields.io/badge/Build-0052CC?style=for-the-badge&logo=githubactions&logoColor=white)
- `source/` - Código fuente de la aplicación wearable.
  ![Source](https://img.shields.io/badge/Source-32CD32?style=for-the-badge&logo=android&logoColor=white)
