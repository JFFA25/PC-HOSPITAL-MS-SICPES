## Contenido

En esta carpeta encontrarás:

- Componentes visuales del sistema.
- Vistas y páginas de la aplicación.
- Recursos multimedia y estilos.
- Configuración de la interfaz web.

> El frontend permite la interacción directa entre el usuario y el sistema.
