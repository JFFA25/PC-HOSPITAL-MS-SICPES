# URs

![User Requirements](https://img.shields.io/badge/User%20Requirements-3F51B5?style=for-the-badge&logo=document&logoColor=white)

Esta carpeta se encuentra en `Docs/URs` y contiene la documentación de los requisitos de usuario del sistema SICPES.

## Descripción

Los requisitos de usuario (URs) describen las necesidades, condiciones y expectativas de los usuarios finales que el sistema debe cumplir. Se enfocan en qué debe hacer el sistema desde la perspectiva del usuario.

## Contenidos esperados

Esta carpeta debe contener documentación relacionada con:

- **Registro y acceso** - Requisitos de autenticación y gestión de usuarios.
  ![Authentication](https://img.shields.io/badge/Authentication-FF5722?style=for-the-badge&logo=lock&logoColor=white)
- **Gestión de pacientes** - Requisitos de creación, actualización y consulta de pacientes.
  ![Patients](https://img.shields.io/badge/Patients-E91E63?style=for-the-badge&logo=user&logoColor=white)
- **Citas médicas** - Requisitos para agendar, modificar y cancelar citas.
  ![Appointments](https://img.shields.io/badge/Appointments-9C27B0?style=for-the-badge&logo=calendar&logoColor=white)
- **Servicios y atención** - Requisitos de servicios médicos, tratamientos y atenciones.
  ![Medical Services](https://img.shields.io/badge/Medical%20Services-F44336?style=for-the-badge&logo=medical&logoColor=white)
- **Reportes e información** - Requisitos de generación de reportes y acceso a datos.
  ![Reports](https://img.shields.io/badge/Reports-FF9800?style=for-the-badge&logo=document&logoColor=white)

> Utiliza este README como guía para organizar los requisitos de usuario del proyecto y facilitar su trazabilidad.
