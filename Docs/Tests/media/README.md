# Evidencias de pruebas (Screenshots)

Este directorio contiene capturas de pantalla y visualizaciones usadas para documentar los tests SQL y NoSQL.

Estructura:

- `Test_SQL/` — capturas de pruebas de generación SQL (10k, 15k, etc.).
- `Test_NoSQL/` — capturas de pruebas de inserciones en MongoDB.

Listado de archivos (ejemplos):

- `Test_SQL/1.Generación automática de población (10000).png` — prueba SQL 10k.
- `Test_NoSQL/1.Inserción básica de valoraciones (1,000 registros).png` — prueba NoSQL 1k.

Incluye un `README.md` dentro de cada subcarpeta `Test_SQL/` y `Test_NoSQL/` con la lista completa y la descripción de cada imagen.
