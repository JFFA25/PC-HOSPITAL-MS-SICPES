# Pruebas de API

Este directorio documenta los casos de prueba implementados para la API híbrida.

## Propósito
Mantener una referencia clara entre los endpoints de la API y los escenarios de prueba documentados.

## Archivos
- `API.md` — Casos de prueba para los endpoints principales de la API.
- `Results.md` — Respuestas reales y sincronización de la documentación con la implementación.
- `media/` — Imágenes de resultados de tests SQL y NoSQL.

## Organización de capturas de pantalla
- `Docs/Tests/media/Test_SQL/` — Screenshots de pruebas de generación SQL.
- `Docs/Tests/media/Test_NoSQL/` — Screenshots de pruebas de generación NoSQL.

## Cobertura de tests
- `API.md` documenta los casos de prueba.
- `Results.md` documenta los resultados esperados y ejemplos de respuestas reales.
- Los nombres de las capturas referenciadas están alineados con los escenarios de prueba.
