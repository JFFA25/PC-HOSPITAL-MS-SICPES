Esta carpeta se encuentra en `Docs/BRs` y contiene los documentos de requisitos de negocio del sistema SICPES.

## Contenido

En esta carpeta encontrarás:

- Definición de procesos de negocio.

- Especificaciones de políticas hospitalarias.
- Diagramas de flujo de negocio.

> Estos documentos definen qué debe hacer el sistema desde la perspectiva del negocio.
