# WebApp

![WebApp](https://img.shields.io/badge/WebApp-4CAF50?style=for-the-badge&logo=react&logoColor=white) ![GUIs](https://img.shields.io/badge/GUIs-32CD32?style=for-the-badge&logo=figma&logoColor=white)

Esta carpeta se encuentra en `Docs/GUIs/WebApp` y contiene los mockups y prototipos de interfaz de usuario para la aplicación web del sistema SICPES.

## Contenido

En esta carpeta encontrarás:

- Wireframes de las páginas de la aplicación web.
- Diseños de interfaces para escritorio y móvil.
- Mockups de paneles de administración.
- Prototipos de formularios y tablas de datos.
