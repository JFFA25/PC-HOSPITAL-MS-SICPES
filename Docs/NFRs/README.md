# NFRs

![NFRs](https://img.shields.io/badge/NFRs-FF6B6B?style=for-the-badge&logo=performance&logoColor=white)

Esta carpeta se encuentra en `Docs/NFRs` y contiene la documentación de los requisitos no funcionales del sistema SICPES.

## Descripción

Los requisitos no funcionales especifican atributos de calidad, desempeño, seguridad, escalabilidad, disponibilidad y otras características técnicas que el sistema debe cumplir, independientemente de las funcionalidades específicas.

## Contenidos esperados

Esta carpeta debe contener documentación relacionada con:

- **Desempeño** - Tiempos de respuesta, throughput y optimizaciones.
  ![Performance](https://img.shields.io/badge/Performance-4CAF50?style=for-the-badge&logo=speedtest&logoColor=white)
- **Seguridad** - Autenticación, autorización y protección de datos.
  ![Security](https://img.shields.io/badge/Security-FF5722?style=for-the-badge&logo=lock&logoColor=white)
- **Escalabilidad** - Capacidad para crecer y manejar carga.
  ![Scalability](https://img.shields.io/badge/Scalability-2196F3?style=for-the-badge&logo=trending-up&logoColor=white)
- **Disponibilidad** - Uptime, redundancia y recuperación ante fallos.
  ![Availability](https://img.shields.io/badge/Availability-9C27B0?style=for-the-badge&logo=check-circle&logoColor=white)
- **Mantenibilidad** - Documentación, código limpio y facilidad de mantenimiento.
  ![Maintainability](https://img.shields.io/badge/Maintainability-FFC107?style=for-the-badge&logo=tools&logoColor=white)

> Consulta esta documentación para asegurar que el sistema cumpla con los estándares de calidad y desempeño requeridos.
