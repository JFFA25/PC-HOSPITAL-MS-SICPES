# Images

![Images](https://img.shields.io/badge/Images-6A5ACD?style=for-the-badge&logo=image&logoColor=white)

Carpeta de recursos gráficos del proyecto SICPES: logos, paleta de colores, mockups y otros activos usados en la documentación y la aplicación.

Contenido principal
- `SICPES_Producto.png` — Logo/producto usado en la interfaz y presentaciones.
- `SICPES_Empresa.png` — Logo institucional / marca de la empresa.
- `colors_scipes.png` — Paleta de colores y guía visual.

Convenciones y recomendaciones
- Formatos: preferir `SVG` para logos escalables; usar `PNG` para imágenes rasterizadas.
- Nombres: conservar los nombres actuales tal como aparecen arriba para evitar referencias rotas.
- Resoluciones: mantener un archivo maestro (alta resolución, p.ej. 1024×1024 o superior) y generar variantes optimizadas para web (p.ej. 300–800 px según uso).

Cómo añadir nuevos activos
1. Añade el archivo a esta carpeta.
2. Usa un nombre descriptivo y consistente (sin espacios, con guiones o guion_bajo).
3. Actualiza este README si el activo será referenciado por la documentación o por el frontend.
